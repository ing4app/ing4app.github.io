# Sito sviluppatore Ing4App

Contenuto da pubblicare nella radice del repository pubblico GitHub `ing4app.github.io`.

Dopo l'attivazione di GitHub Pages devono essere disponibili:

- `https://ing4app.github.io/`
- `https://ing4app.github.io/app-ads.txt`
- `https://ing4app.github.io/robots.txt`

In Google Play Console usare `https://ing4app.github.io/` come sito web dello sviluppatore. L'informativa di SpeseAI rimane disponibile su `https://ing4app.github.io/speseai-privacy/`.
